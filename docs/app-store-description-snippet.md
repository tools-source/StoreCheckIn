# StoreCheckIn App Information

Effective date: March 13, 2026

Short description:

StoreCheckIn helps stores track employee check-ins, check-outs, payroll-ready time entries, and archived work history.

Feature summary:

- Sign in with Apple account access
- Active Employees, Archive, and Settings tabs
- Employee check-in and check-out tracking
- Archive/history tools that move worked hours into Archive while keeping employees active
- Weekly filtering inside archived employee history
- Local shift reminders for both check-in and check-out
- Store name setting for the Employees screen title
- 6-digit PIN app lock with Face ID or Touch ID when available
- Forgot PIN reset by re-authenticating with the same Apple account
- Exportable timesheet data and local account deletion from Settings

Subscription note:

An active App Store subscription is required to use paid app features. Subscription billing and management are handled by Apple.
